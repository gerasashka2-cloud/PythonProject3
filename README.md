# Учебный проект по Python

### **Установка:**

1. **Клонируйте проект** с этого репозитория, используя в PyCharm (в командной строке терминала) команду:
```
git clone git@github.com:gerasashka2-cloud/PythonProject3.git
```
2. **Инициализируйте виртуальное окружение** командой:
```
python -m venv <название_окружения>
```
*Например:*
```
python -m venv venv
```

3. **Активируйте окружение** с помощью команды:
*   на macOS и Linux:
```
source venv/bin/activate
```
*   на Windows:
```
venv\Scripts\activate
```
*Или используйте `poetry shell` для активации виртуального окружения (доступно только при установленном плагине `poetry-plugin-shell`).*
4. **Установите все зависимости проекта** (указанные в файле `requirements.txt`) командой:
```
pip install -r requirements.txt
```
Также можно установить линтеры на выбор, используя Poetry с помощью команды:
```
poetry add --group lint <линтер>
```
Замените <линтер> на имя нужного линтера, например `flake8` или `mypy`, и они будут указаны в pyproject.toml. 
Если же использовать команду:
```
poetry add <линтер>
```
Тогда линтеры будут установлены для всего PyCharm

Проект по тестированию функций на Python

Описание

Этот проект содержит модули и тесты для функций, связанных с обработкой данных банковских карт и счетов. Основная цель — продемонстрировать навыки тестирования с использованием библиотеки pytest.


Структура проекта


		• src/: содержит исходный код проекта.


masks.py: функции для маскирования номеров карт и счетов.

processing.py: функции для фильтрации и сортировки данных.

widget.py: функции для обработки и преобразования данных.

generators.py: функция содержит генераторы для обработки данных.



		• tests/: содержит тесты для модулей проекта.


test_masks.py: тесты для функций из masks.py.

test_processing.py: тесты для функций из processing.py.

test_widget.py: тесты для функций из widget.py.

test_generators.py: тесты для функции из generators.py.




Установка и запуск тестов


		1. Клонируйте репозиторий:

git clone <URL репозитория>


		2. Установите необходимые зависимости:

pip install -r requirements.txt


		3. Запустите тесты:

pytest
